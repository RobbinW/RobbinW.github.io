# Ruixiang Wang

Source for Ruixiang Wang's academic homepage at [robbinw.github.io](https://robbinw.github.io/).

The site is a lightweight static page built with HTML, CSS, and JavaScript. To preview it locally, run:

```bash
python3 -m http.server 4173
```

Then open [http://127.0.0.1:4173/](http://127.0.0.1:4173/).
